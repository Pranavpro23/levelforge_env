What is LevelForge?

LevelForge trains a 0.5B language model (Qwen2.5) to design 2D platformer levels using GRPO reinforcement learning. The model learns to create levels tailored to different player personalities (brave, cautious, explorer) using only A* pathfinding rewards—no LLM judge needed.

How Reward Works

  • Solvable: A* finds path from P to G (hard gate)
  • Difficulty Band: Path length matches target
  • Coin Reachable: Coins lie on A* path
  • Symmetry: Aesthetic layout quality
  • Personality Match: Level suits player type
  • Format: Valid reasoning tags present

API Endpoints

  • POST /reset — Start new episode
  • POST /step — Execute action
  • GET /state — Current episode state
  • GET /health — Server health check
  • GET /curriculum_level — Current curriculum info
  • GET /scenarios — All curriculum levels
